# Word & Line Counter CLI

A simple Node.js command-line application that reads a text file and counts the number of lines, words, and characters.

## Requirements

- Node.js
- npm

## Installation

Clone or download the repository and run:

npm install

## Usage

Run the program using:

npm start sample.txt

## Example Output

--- Word & Line Counter ---
File: sample.txt
Lines: 5
Words: 57
Characters: 353

## Features

- Counts lines
- Counts words
- Counts characters
- Handles missing filenames
- Handles files that do not exist

## Technologies Used

- Node.js
- JavaScript
- fs/promises
- ESM
