# Word & Line Counter CLI

A lightweight Node.js Command Line Interface (CLI) tool that counts lines, words, and characters in a given text file.

## Features
- Asynchronous file reading using Node.js `fs/promises`.
- Graceful error handling for missing files or invalid input.
- ESM module standard support.
